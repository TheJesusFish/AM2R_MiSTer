# Focused reference notes

Start with [bootstrap.md](../bootstrap.md), not this directory. The original archive's long handbooks were condensed to the material useful for the proposed AM2R hybrid.

- [HDL notes](hdl-notes.md): clock/reset and CDC contracts, widths, memories/DSPs, timing and simulation.
- [MiSTer integration notes](mister-integration-notes.md): HPS/framework coexistence, shared DDR3, presentation, audio, controllers and saves.
- [Source register](../docs/sources.md): primary URLs, scope and evidence limits.
- [Adaptation rationale](../docs/adaptation.md): what was retained and discarded.

These notes are advisory, not a replacement for the selected upstream code or vendor specification. No underlying MiSTer source checkouts or generic memory RTL have been bundled. Fetch and pin them only when the corresponding milestone needs them.
