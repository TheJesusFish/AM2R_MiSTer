
The Windows executable, DLLs, desktop README, configuration files, and saves
do not belong in `AM2R.zip`. The required files total 87,581,625 uncompressed
bytes. The supported AM2R 1.1 `data.win` has SHA-256:

```text
36E4A251D7B687F2D742A8E911CB1E1185AEA99E36529FCF32CD18D445A355E3
```

Any normal ZIP program may be used. Compression level does not matter, so the
finished ZIP's size and hash may vary. Do not distribute the completed archive.
