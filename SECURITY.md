# Security policy

This is an experimental MiSTer core and game-runtime wrapper. It processes a
user-supplied ZIP and runs native ARM code; use only game data and binaries you
trust.

For a security issue, use GitHub's private security-advisory feature for the
repository rather than posting exploit details or private files in a public
issue. Do not include credentials, save states, checkpoints, or copyrighted
game data in a report.
